# Play Store assets

Generated by `make_store.py` from emulator captures of the 1.0.27 release build.

| File | Play Console field |
|---|---|
| `icon_512.png` | App icon (512 x 512) |
| `feature_graphic_1024x500.png` | Feature graphic |
| `phone_01_*.png` ... `phone_07_*.png` | Phone screenshots (1080 x 1920, upload in this order) |

To regenerate: capture raw 1080x2340 screenshots named `home.png`, `session.png`, `browser.png`,
`player.png`, `mirror.png`, `library.png` and `dark.png` (use System UI demo mode for a clean
status bar), then run `python make_store.py <raw_dir> store/play-assets`.
